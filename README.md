# OrgaBuddy

OrgaBuddy is a rehearsal scheduling app for multiple bands. It combines weekly availability painting, ranked overlap suggestions, and confirmed rehearsal calendars in a dark SaaS-style dashboard.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui-style component layer
- Supabase Auth
- PostgreSQL
- Prisma ORM
- FullCalendar
- Zod
- Lucide icons
- date-fns

## Included MVP

- Email/password login with Supabase Auth
- Admin/member role handling
- Band creation and membership management
- Required vs optional members
- Custom weekly availability grid
- Band-level availability heatmap
- Scheduling engine in [generateSuggestions.ts](/Users/hugodubio/ORGABUDDY/lib/scheduling/generateSuggestions.ts)
- Ranked rehearsal suggestions with confirmation flow
- Confirmed rehearsal calendars and list views
- Prisma schema, seed script, and environment example

## Setup

1. Copy `.env.example` to `.env.local`.
2. Fill in PostgreSQL and Supabase values.
3. Install dependencies:

```bash
npm install
```

4. Generate Prisma client:

```bash
npm run db:generate
```

5. Run migrations:

```bash
npm run db:migrate
```

6. Seed demo data:

```bash
npm run db:seed
```

7. Start the app:

```bash
npm run dev
```

## Environment

Use [`.env.example`](/Users/hugodubio/ORGABUDDY/.env.example) as the template.

- `SUPABASE_SERVICE_ROLE_KEY`
- `NEXT_PUBLIC_APP_URL`
- `DEV_AUTH_PASSWORD`

## Seed Notes

- The seed creates:
  - 1 admin user
  - 2 sample bands
  - 6+ member records
  - memberships
  - sample availability blocks
  - confirmed rehearsals
  - attendance rows
- If `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` are set, the seed also provisions Supabase Auth users.
- If Supabase env vars are not set locally, the app falls back to a development-only cookie login using the seeded users and `DEV_AUTH_PASSWORD`.
- Seeded demo login:
  - Email: `admin@orgabuddy.app`
  - Password: `DemoPass123!`

## Notes

- Availability input is custom and grid-first. FullCalendar is only used for confirmed rehearsal views.
- Suggestions are stored for MVP simplicity but generated by the isolated scheduling module.
- Conflict prevention checks same-band overlaps and cross-band member conflicts before rehearsal confirmation.
